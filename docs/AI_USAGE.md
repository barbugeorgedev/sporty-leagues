# AI Usage Notes

I used AI tools (primarily ChatGPT and Cursor) as a development companion.

## How AI was used
- Helped brainstorm a clean, time-boxed solution structure for the assignment
- Assisted with UI layout exploration based on my prompts and constraints
- Acted as a lightweight PR/review companion to sanity-check edge cases and API handling
- Helped refine documentation wording and explain design decisions clearly

## How AI was *not* used
- The solution was not generated end-to-end by AI
- Core implementation decisions, architecture, state flow, and final code structure were chosen and reviewed manually
- I intentionally kept the implementation lightweight and aligned with the assignment scope rather than over-engineering with unnecessary abstractions

## Notes
I used AI primarily to improve speed, clarity, and review quality within the 90-minute time-box, while keeping ownership of the final implementation and technical decisions.
